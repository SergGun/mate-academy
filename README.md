## Purpose

This monorepo contains all Mate Academy coursework projects in a single repository, with each project preserved in its own directory. The original Git history for each project is maintained in the respective source repositories.

## Directory Structure

## Git History

Each project was imported using git subtree add --squash, which creates a single commit per project containing the final state of that project's master branch. The full commit history for each project is preserved in its original repository (linked above).

## Original Repositories

All 40 original repositories remain untouched and accessible at their original URLs under the SergGun account.
